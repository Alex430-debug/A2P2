IMPORTANT AFTER REPLACING AN OLD VERSION
- GitHub Pages + the old offline cache can briefly show the previous version.
- After GitHub finishes deployment, open the page in Safari and refresh it twice.
- If you installed it on the iPhone Home Screen and it still shows the old version,
  remove that Home Screen copy, open the GitHub Pages URL in Safari again, then Add to Home Screen again.
